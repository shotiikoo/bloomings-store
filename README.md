# Bloomings Store

ყვავილების მაღაზიის საიტი + ადმინის გვერდი. არანაირი დამოკიდებულება არ სჭირდება (მხოლოდ Node.js 18+).

## ფაილები
- `server.js` სერვერი (კატალოგი, შეკვეთები, ადმინის ავტორიზაცია)
- `public/index.html` მაღაზიის საიტი
- `views/admin.html` ადმინის გვერდი (ხელმისაწვდომია მხოლოდ საიდუმლო მისამართზე, `/admin` არ არსებობს)
- `data/db.json` იქმნება ავტომატურად პირველ გაშვებაზე (კატალოგი + შეკვეთები), `data/uploads/` ფოტოებისთვის

## ლოკალურად გაშვება
```
# Windows PowerShell
$env:ADMIN_PASSWORD="შენი-გრძელი-პაროლი"; node server.js

# Mac / Linux
ADMIN_PASSWORD="შენი-გრძელი-პაროლი" node server.js
```
საიტი: http://localhost:3000 — ადმინი: მისამართი დაიბეჭდება კონსოლში („Admin page: /...“), ან დააყენე `ADMIN_PATH`

## Render-ზე
1. ატვირთე ეს საქაღალდე GitHub-ზე (`data/` და `.env` გამორიცხულია `.gitignore`-ით).
2. Render → New → Web Service → აირჩიე repo. Build Command: ცარიელი (ან `npm install`). Start Command: `node server.js`.
3. Environment Variables:
   - `ADMIN_PASSWORD` — ადმინის პაროლი, მინიმუმ 8 სიმბოლო (უკეთესია 14+). **სერვერი არ ჩაირთვება მის გარეშე.**
   - `ADMIN_PATH` — ადმინის საიდუმლო მისამართი: 16–64 სიმბოლო (ასოები, ციფრები, `-`, `_`), მაგ. შენით შეკრული გრძელი შემთხვევითი ტექსტი. ადმინი იქნება `https://დომენი/ეს-ტექსტი`. თუ არ დააყენე, სერვერი თვითონ შექმნის და Render Logs-ში დაწერს „Admin page: /...“, მაგრამ დისკის გარეშე ის ყოველ გადატვირთვაზე შეიცვლება, ამიტომ **დააყენე ADMIN_PATH**.
   - `SESSION_SECRET` — (არასავალდებულო) შემთხვევითი გრძელი ტექსტი.
   - `DATA_DIR` — იხილე ქვემოთ.
4. **მონაცემების შენახვა:** Render-ის უფასო გეგმაზე დისკი წაიშლება ყოველ ხელახალ დეპლოიზე/გადატვირთვაზე, ანუ დაიკარგება შეკვეთები, ფასები და ფოტოები. მუდმივი შენახვისთვის დაამატე Render **Disk** (ფასიან გეგმაზე), mount path `/var/data` და დააყენე `DATA_DIR=/var/data`.
5. ადმინი: `https://შენი-დომენი/<ADMIN_PATH>` (ეს ბმული არსად არ გამოაქვეყნო)

## უსაფრთხოება
- ადმინის გვერდიც და მისი API-ც არ არსებობს (404) მათთვის, ვინც საიდუმლო მისამართს არ იცნობს, ხოლო ვინც იცის, პაროლიც უნდა შეიყვანოს.
- ყველა ცვლილება მოწმდება სერვერზე; პაროლის გარეშე ვერავინ შეცვლის ფასებს, ყვავილებს ან ნახავს შეკვეთებს.
- შეკვეთის ჯამს სერვერი თვითონ ითვლის კატალოგის ფასებით (ბრაუზერიდან მოსულ ფასს არ ენდობა).
- პაროლის შესვლის მცდელობა შეზღუდულია (8 მცდელობა / 15 წუთი), სესია 12 საათია.
- თუ პაროლი დაგავიწყდა ან გაჟონა, შეცვალე `ADMIN_PASSWORD` Render-ში; ძველი სესიები გაუქმდება.

## გადახდა
ონლაინ გადახდა ჯერ არ არის ჩართული: შეკვეთა ჩნდება ადმინში სტატუსით „ახალი“, მომხმარებელს ტელეფონით უკავშირდებით. გადახდისთვის საჭიროა გადახდის პროვაიდერი (მაგ. TBC, BOG, Stripe).
